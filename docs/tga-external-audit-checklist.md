# External study handoff checklist

Copy this checklist into the audit record; do not treat a checked software step as independent scientific approval.

- [ ] Exactly six original JSON files, no symlinks or extras
- [ ] Original file bytes retained with independent receipt metadata
- [ ] Exact repository commit and runtime recorded
- [ ] Full study-package validation completed
- [ ] Conservative review summary exported
- [ ] SHA-256 file inventory exported
- [ ] Cross-linked audit bundle exported
- [ ] Bundle checksum conveyed over separately trusted channel
- [ ] Receiving auditor re-computed hashes and compared trusted digest
- [ ] Full input-backed bundle verification passed
- [ ] Offline-only verification clearly distinguished from replay
- [ ] Preregistration independently checked against external registry
- [ ] Reviewer identities, affiliations, and conflicts independently checked
- [ ] Label provenance and adjudication process independently assessed
- [ ] Scientific validity independently assessed
- [ ] Exceptions and unverified claims documented

See [Independent audit handoff](tga-independent-audit-handoff.md) for commands and evidence boundaries.
